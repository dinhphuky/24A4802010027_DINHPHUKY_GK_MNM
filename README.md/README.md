## Trích xuất dữ liệu

### 4.1. Xuất kết quả truy vấn câu 3.4 ra file CSV
- **Công cụ thực hiện:** Sử dụng tính năng **Save results to file** (Export) trực tiếp trên giao diện Query Tool của pgAdmin 4.
- **File kết quả:** `export/ketqua_cau3_4.csv` (định dạng CSV, có dòng tiêu đề cột).

### 4.2. Sao lưu toàn bộ cơ sở dữ liệu gk_thuvien
- **Công cụ thực hiện:** Sử dụng tính năng **Backup** (với định dạng **Plain**) trực tiếp trên pgAdmin 4.
- **File sao lưu:** `export/gk_thuvien_backup.sql` (chứa toàn bộ cấu trúc và dữ liệu của cơ sở dữ liệu `gk_thuvien`).
